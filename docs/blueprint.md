# **App Name**: Verde Budget

## Core Features:

- Manual Expense Entry: Add expenses manually, specifying amount, date, and category.
- Expense Categorization: Categorize expenses into predefined categories.
- Budget Setting: Set monthly budget goals for different categories.
- Spending Charts: Visualize spending patterns with bar graphs. Display data by time, and category
- AI-Powered Categorization: Suggest expense categories tool using natural language processing based on expense descriptions.
- Dashboard Overview: View a dashboard with key financial insights such as total spending, budget vs. actual, and category breakdowns.

## Style Guidelines:

- Primary color: Soft green (#90EE90) to evoke a sense of growth and stability.
- Background color: Very light green (#F0FFF0) to provide a clean and calming backdrop.
- Accent color: Pale blue (#ADD8E6) for interactive elements and highlights, creating contrast while remaining harmonious.
- Body and headline font: 'PT Sans' (sans-serif) for a modern yet approachable feel, suitable for both headings and body text.
- Use minimalist icons to represent expense categories and dashboard elements, enhancing visual clarity.
- Emphasize a clean and intuitive layout with clear information hierarchy to facilitate ease of use.
- Incorporate subtle transitions and animations when displaying data updates and category selections for improved user experience.
